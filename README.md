# TopIN - Mobile App UI/UX Design
Proyek ini merupakan portofolio dan dokumentasi desain Antarmuka Pengguna (*UI/UX*) untuk aplikasi mobile bertema pendakian gunung **TopIN** yang dirancang menggunakan Figma[cite: 4, 9]. Aplikasi ini dibuat untuk memberikan pengalaman yang intuitif bagi para pendaki dalam mencari destinasi gunung impian, melihat informasi detail, hingga mengelola daftar favorit.

### Tujuan Desain (Design Goals)
  1. Informasi Destinasi: Menyajikan informasi lengkap mengenai berbagai destinasi gunung populer beserta detail ketinggian dan lokasinya dengan tampilan visual yang menarik[cite: 5, 8].
  2. Manajemen Favorit: Memudahkan pengguna dalam menyimpan dan mengakses kembali daftar gunung favorit mereka[cite: 2, 3].
  3. Navigasi Intuitif: Menghadirkan alur pengguna (*user flow*) yang mulus mulai dari halaman sambutan (*splash screen*), proses masuk, hingga halaman utama[cite: 4].
